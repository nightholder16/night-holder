# Бот офферов подарков Telegram (бизнес-аккаунт)

Бот делает ровно то, что на скринах: продавец пишет `.buy` в чате с покупателем,
бот публикует оффер, а после нажатия «Принять» отправляет покупателю инструкцию
с кнопкой передачи подарка.

## Команда

```
.buy <ссылка на подарок> <цена> <gram|stars> <en|ar|кit>
```

Примеры:

```
.buy https://t.me/nftchannel/21490 1000 gram
.buy https://t.me/nftchannel/21490 1000 stars en
.buy https://t.me/nftchannel/21490 500 gram ar
```

* порядок аргументов строго такой: **ссылка → цена → валюта → язык**;
* язык можно не указывать — тогда русский;
* валюта: `gram` (показывается как `💎 GRAM`) или `stars` (`⭐ STARS`);
* оффер уходит **в тот же чат**, где была написана команда;
* необязательный 5-й аргумент — точное название подарка, если Telegram отдаёт не то:
  `.buy https://t.me/nftchannel/21490 1000 gram en Swiss Watch #21490`;
* дополнительно: `.offers` — список активных офферов, `.help` — справка;
* `.version` — версия запущенного кода (если печатает старую дату — бот не перезапущен).

Токен уже прописан в `.env`: бот **@lgjdakgjads_bot** (SafeMod).

## Что делает бот

1. **Оффер** — одно сообщение с фото подарка (берётся с публичного поста `t.me/s/...`) и
   подписью один в один со скрином:

   ```
   Telegram
   Vintage Cigar #23849
   ────────────────
   ПОКАЗАТЬ ПОДАРОК

   Пользователь предлагает Вам
   100 GRAM за подарок Vintage Cigar #23849.

   Предложение действует ещё 6 ч. 0 мин.. · 22:38
   ```

   Кнопки: `[ ⊗ Отклонить ][ ✓ Принять ]`. Сообщение с самой командой `.buy ...`
   удаляется сразу после отправки оффера (как и сообщения других команд).
2. **После «Принять»** Telegram сам показывает своё предупреждение (скрин 2) — бот
   не пишет про себя ничего. Затем покупателю в личку уходят **два** сообщения (скрин 3):
   * текст `Заказ #TG-XXXXXXXXXX / Покупатель зарезервировал ... / инструкция`;
   * блок подарка с фото и кнопками `Передать NFT ↗` (`tg://send_gift?to=<username>`)
     и `✅ Подтвертить передачу` — кнопка-заглушка, ничего не делает.
3. Офферы живут `OFFER_TTL_HOURS` (по умолчанию 6 часов), повторно принять нельзя.

### Что нельзя изменить с стороны бота

* **Подпись «SafeMod, 22:38» возле времени.** Это клиент Telegram помечает сообщения,
  отправленные через бизнес-подключение (имя подключённого бота). Bot API не умеет её
  отключать. Если подпись не нужна — поставь в `.env` `USE_BUSINESS_CONNECTION=0`,
  тогда бот пишет как обычный бот, но и предупреждение Telegram при нажатии «Принять»
  показываться не будет.
* **Розовый цвет** слов «Telegram» и «ПОКАЗАТЬ ПОДАРОК» — это фирменный стиль нативного
  блока подарка. У бота ссылки и текст наследуют цвет темы клиента.

## Установка

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Скопируй `.env.example` в `.env` и вставь токен:

   ```
   BOT_TOKEN=1234567890:AA...
   ```

3. Запуск:

   ```bat
   start.bat
   ```

   Либо вручную:

   ```bat
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   .venv\Scripts\python bot.py
   ```

## Подключение как бизнес-аккаунт

1. Открой **настройки Telegram** → **Устройства** → **Подключить бота** (или через
   @BotFather: `/mybots` → твой бот → **Configure** → **Business**).
2. Выбери свой аккаунт и выдай боту право **«Работать от имени аккаунта»**.
3. Как только бот подключится, он пришлёт апдейт `business_connection` и запомнит
   `business_connection_id` — в логе появится строка `Бизнес-подключение: id=...`.
4. После этого `.buy` в любом чате/ЛС бизнес-аккаунта будет работать: бот отвечает
   от имени аккаунта, а инструкция уходит покупателю в личку от этого же аккаунта
   (именно поэтому Telegram показывает предупреждение со скрина 2).

В обычной группе бот тоже сработает, если у него выключен режим приватности
(удалить/отключить Privacy Mode у бота в группе).

## Настройки (.env)

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `BOT_TOKEN` | — | токен бота (обязательно) |
| `OFFER_TTL_HOURS` | `6` | время жизни оффера |
| `RESERVE_HOURS` | `24` | «Резерв действует N ч.» в инструкции |
| `DEFAULT_LANGUAGE` | `ru` | язык, если в `.buy` не указан |
| `SEND_GIFT_LINK_TEMPLATE` | `tg://send_gift?to={target}` | ссылка кнопки «Передать NFT» |
| `LOG_CHAT_ID` / `LOG_TOPIC_ID` | пусто | дублировать сделки в канал/чат |

## Частые вопросы

* **Сообщение с `.buy ...` не удаляется.** Telegram не дал боту права удалять чужие
  сообщения. В группе выдайте боту права администратора с правом «Удалять сообщения»
  (или при подключении бизнес-аккаунта отметьте право удаления). Причина пишется в
  `offers.log` строкой «Команда .buy осталась в чате …».
* **Картинка подарка не подставилась.** Бот берёт её из вашей ссылки. Если ссылка
  ведёт на закрытый канал или страницу без превью — можно указать картинку явно
  в конце команды: `.buy <ссылка> 100 gram en Vintage Cigar #23849 https://cdn.../pic.jpg`.
  Если ссылка уже ведёт на файл `.jpg/.png` — она используется как картинка.

* **Подарок не отображается картинкой.** Бот берёт превью с публичного поста
  `t.me/s/<канал>/<id>`. Если канал закрытый — пришлите боту ссылку на публичный пост,
  либо бот отправит оффер без картинки (название подарка будет взято из ссылки).
* **Кнопка «Передать NFT» не открывает окно подарка.** Проверьте, что клиент
  Telegram поддерживает `tg://send_gift`. Если нет — в `.env` замените шаблон на
  `https://t.me/{target}` или свой.
* **Бот не видит команду в группе.** Включите права на чтение сообщений
  (Privacy Mode выключить) или используйте бизнес-подключение.
